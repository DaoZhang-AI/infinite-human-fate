# 四层念头实现任务书

本任务实现人物归并与四层独立念头，保留既有皮肤、世界事件、好感、情绪、性格弧、约定及物品功能。

## 产品规则

- 人类页包含所有已知 Char1、Char2、NPC。在场显示完整人物卡，离场每人一行当前状态。
- 目前想法从最新正文实时推演，只留当前内存。打开面板和重新打开聊天不发模型请求，不保存当前想法，不保留其历史。
- 短期独立生成，默认每 5 个 AI 回合浮现。执行回执到达后删除活动条目，根据结果生成新条，不升级成长期。
- 长期与执念各自默认 10、15 回合，可独立配置。保留历次行动、结果、进展和下一次具体行动。
- 长期挫败阈值由模型选 1..10，代码夹紧，缺省 3。达到上限按放弃归档。长期只因完成或放弃归档，执念只因达成归档。
- 浮现仅代表安排尝试，不代表执行或成功。每条念头和尝试有稳定 ID，回执必须精确匹配两者。无回执保持等待，不重复发起同一尝试。

## 回合、撤销与存储

一个回合为一条 AI 回复，包含被大总结隐藏的旧 AI 回复。隐藏只改变展示，不撤销已发生的回合与回执。用户消息不计数，继续生成和重 roll 同一楼不加回合。状态绑定完整消息前缀指纹，回执重放按当前分支折算；swipe 只排除即将重写的末条可见 AI 回复，保留被隐藏的旧历史。

内部撤销记录只存新增念头、下一行动变化、派发尝试这些增量，不为目前想法或没有变化的结果写事件。最多保留最近 128 个 AI 回合的撤销范围，超过 512 条操作时提前生成检查点。检查点保留所有长期/执念的真实历史，已执行短期不进入人物历史；旧短期仅在撤销窗口内的操作中保留，不送给模型。编辑或删除早于检查点的楼会暂停念头自动更新并明确提示，不能保证任意久远的分支切换；恢复原分支或导入编辑前的记忆后可继续。

旧 ideas、parkedIdeas、log 原样保留，活动旧念头映射为长期层，迁移有版本号且只做一次，不再执行旧版清空式迁移。旧缓存正文存在在场行时免费补齐，缺字段与显式空数组严格区分。

当前想法随正常生成后的任务更新，与该轮人物规划共用请求；失败显示未更新，不把上轮想法冒充本轮。副 API 未配置时不自动增加后台请求，手动按钮可使用现有连接。

所有设置与持久状态只存插件自己的 JSON。保存串行化，保留内存对象身份，异步任务返回后检查聊天代次和正文前缀。导入使在途任务失效。所有插件内部 import 使用统一版本查询参数，避免入口新、子模块旧。

多设备保存时，如果远端 revision 更高且念头引擎不同，拒绝上传并停止自动重试，保留本地内存供导出。不同检查点暂不自动合并。文件接口没有原子比较并写入功能，同时读到同一 revision 后的跨设备竞争仍不能完全排除，避免两台设备同时改同一聊天。

长期卡的旧版记录会注明“旧版念头与日志，原样保留”。旧版 surfacedAt 仅说明浮现，不伪造为新生命周期的已执行历史。

## 验证

仅使用插件内合成人物/聊天 fixture 与 mock，不读真实聊天或密钥，不请求真实模型。覆盖解析到 UI 的在场链路、空场、旧楼、重复迁移、各层独立、回执幂等、重 roll/继续/删除、阈值、失败重试、保存竞态和跨聊天。保留独立 UI fixture 供审查。旧开发目录不改动，不运行含真实服务或数据读取的测试。
