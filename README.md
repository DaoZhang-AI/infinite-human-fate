# 模拟人生

> 原名「无限人类命运」,2026-09-18 改名。仓库地址、文件夹名、记忆文件都没变,装过的直接更新就行。

RP 长局记忆插件。给酒馆(SillyTavern)用的扩展,贴地址就能装。

聊天一长,模型就开始忘事、开始把人演回从前、开始让所有人随叫随到。
这个插件把"记住什么、发多少、什么时候发"接管过来。

面板里三个分页叫「无限 · 人类 · 命运」,名字出自《无限恐怖》:

| | 管什么 |
|---|---|
| **无限** | 摘要、时间线、召回 |
| **人类** | 全部 char/NPC、四层念头、好感度、情绪、性格弧、约定账、物品账 |
| **命运** | 长期念头、执念的尝试与归档，以及世界事件 |

### v0.12.0 四层念头

在场人物显示完整卡片，离场人物每人一句当前状态。目前想法在每次正文更新后推演，只留当前内存；打开面板或重新打开聊天不会调用模型。自动推演需要副 API，也可手动推演。

短期、长期、执念独立，默认每 5 / 10 / 15 个 AI 回合浮现，可分别设置。用户连发、同楼重 roll 和继续生成不额外计回合；被大总结隐藏的旧回复仍算已发生回合。短期执行后按结果换新，长期记录全部尝试并在完成或放弃时归档，执念只在达成时归档。一次浮现不是成功，必须有对应尝试编号的明确结果回执。

旧念头和日志保留，旧版浮现记录不冒充执行结果。内部撤销窗口最多 128 个 AI 回合，操作超过 512 条时可能提前建立检查点；长期与执念的真实历史不裁剪。编辑检查点之前的正文会暂停自动念头更新，恢复原分支或导入编辑前记忆后继续。不同设备的较新念头发生冲突时停止上传并提示先导出本地记录，不自动覆盖；当前文件接口不能保证同时写入的原子性。

离线验证：`node --experimental-vm-modules --test tests/*.test.mjs`。界面审查：用 `node --experimental-vm-modules tests/render-fixture.mjs` 生成 `tests/ui-fixture.html`，然后直接打开该文件。测试与 fixture 都只用合成数据和 mock，不请求真实 API。

## 装

酒馆 → 扩展 → 安装扩展 → 贴这个仓库地址。

装完在「扩展」抽屉里找到「模拟人生」,勾上**开启插件**。

## 两条贯穿全局的设计

**一、模型只写 ±几和事件,所有的数都由插件算。**
好感、性格弧这些,模型只在回复末尾的记账块里写一行「Char1 +2 User 当众替他说了话」,
加减、封顶、分档、过期全在代码里。反过来给模型看的时候也不给数字,
只给「朋友,肯为你花时间」这样的文字档。给了数字它就会自己去对齐、去算错。

**二、这些状态不存死值,每次对账从各层的增量重新折算。**
所以你删楼、滑 swipe、开分支,数全都自动跟着变,不用专门修。
唯一例外是「命运」那一块,幕后按定义就是正文里没发生的事,聊天记录里没有它的影子,
只能由后台推演写进记忆文件存死。

## 数据放哪

全部在 `data/<user>/user/files/` 下面自己的 json 里:

- `infinite-human-fate.config.json` 设置
- `infinite-human-fate.index.json` 聊天 → 记忆文件的索引
- `infinite-human-fate.mem.<id>.json` 每场聊天的记忆

**settings.json 一个字都不写**,那会让酒馆开屏变慢。聊天原文也一个字不改,
所有删减替换都只发生在"发出去之前的副本"上。

## 要 key 吗

不要也能用。召回会退化成按专名找。

想用向量召回的话,在面板里填(⚙️ 设置里的「向量召回」,嵌入和重排各自填地址、key、模型,重排可不填),经酒馆服务器转发(装了 server-plugin 时)或浏览器直连。

补记账、压时间线、幕后推演这些后台活可以挂一个"副 API",
从酒馆自己的连接配置或者 API 管理器里选,**请求经酒馆服务器发出、用酒馆密钥库里的 key,
插件不碰也不存任何 key**。
